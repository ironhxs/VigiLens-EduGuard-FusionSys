## 🎨 制作建议

### 截图规范
- **分辨率**: 1920x1080 或 1280x720
- **格式**: PNG（界面）、JPG（照片）
- **文件大小**: <500KB（压缩后）
- **命名**: 使用英文小写，下划线分隔

### GIF动图规范
- **尺寸**: 800x600 或更小
- **帧率**: 10-15 FPS
- **时长**: 5-15秒
- **文件大小**: <5MB
- **颜色**: 优化色板减小文件

### 图片优化工具
- **TinyPNG**: https://tinypng.com/
- **Squoosh**: https://squoosh.app/
- **ImageOptim**: https://imageoptim.com/
