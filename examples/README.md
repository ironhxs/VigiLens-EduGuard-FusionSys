# Examples - 示例代码

本目录包含各种使用示例和快速开始脚本。

## 📁 文件说明

### audio_quickstart.py
音频暴力检测快速示例，展示：
- 训练模型的完整流程
- 推理/预测的使用方法
- 命令行和 Python API 两种方式

## 🚀 使用方法

### 训练示例
```bash
python examples/audio_quickstart.py --mode train
```

### 推理示例
```bash
python examples/audio_quickstart.py --mode inference
```
