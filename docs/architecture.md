# 系统架构文档

## 总体架构

VigiLens-EduGuard-FusionSys 采用三层分布式架构设计，实现从边缘到云端的智能分析。

## 1. 边缘采集层

### 功能
- 实时视频和音频采集
- 轻量级模型初步判断
- 减少数据传输带宽

### 技术选型
- **轻量级检测模型**: YOLOv5/YOLOv7
- **模型优化**: 量化、剪枝
- **硬件**: 边缘计算设备（如Jetson Nano）

### 工作流程
```
摄像头 → 实时采集 → YOLO检测 → 初步筛选 → 超过阈值 → 上传服务器
```

## 2. 服务器推理层

### 功能
- 视频序列深度分析
- 音频情绪识别
- 多模态特征融合
- 风险评估和预警

### 技术架构

#### 2.1 视频分析模块
- **模型**: VideoSwin Transformer
- **输入**: 32帧视频序列 (224×224)
- **输出**: 暴力行为概率分数
- **特性**: 
  - 时空特征提取
  - 长时序依赖建模
  - 高准确率识别

#### 2.2 音频分析模块（规划中）
- **模型**: CNN + ConvLSTM
- **输入**: 音频梅尔频谱
- **输出**: 情绪分类（愤怒、恐惧等）
- **特性**: 实时情绪检测

#### 2.3 多模态融合
```python
# 融合策略
final_score = α × video_score + β × audio_score
```

### 推理服务
- **框架**: Flask RESTful API
- **接口**:
  - `/predict`: 单视频推理
  - `/batch_predict`: 批量推理
  - `/status`: 服务状态查询

## 3. 人工审核层

### 功能
- 可视化展示检测结果
- 人工复核高风险事件
- 预警通知管理
- 历史记录查询

### 界面
- **技术**: Gradio Web UI
- **功能**:
  - 视频上传和预览
  - 实时推理展示
  - 结果可视化
  - 事件标注

### 1. 模型优化
- INT8量化（减少模型大小和推理时间）

- 模型剪枝（去除冗余参数）

### 2. 推理优化
- TensorRT加速
- 批处理
- 异步推理
- GPU内存优化

### 3. 系统优化
- 缓存机制
