# VigiLens-EduGuard-FusionSys

**慧瞳智盾：多模态融合的校园暴力行为智能感知系统**

**项目背景**
近年来，校园暴力行为，特别是霸凌行为越来越受到社会的关注，因此有效的校园暴力行为发现和干预技术及产品具有重大需求。现有的基于毫米波雷达的探测方法、基于语音探测的方法均存在明显的局限性，因此该团队**研究并实验一种融合人体行为识别、表情识别、语音识别等多信息要素的校园暴力行为识别系统。前端为形态隐蔽的图像和音频采集装置，后端平台软件完成各类识别算法和信息融合，并具有可视化和预警功能。**

本项目瞄准现有智能化传统单一方法检测校园暴力行为误判率高、预警不及时的问题，拟设计一种融合视频和音频信息的多模态校园暴力检测系统，在视频上使用轻量化EfficientNet模型提取视频静态帧帧暴力特征，使用输入LSTM在动态时间序列进行分析；音频方面使用CNN提取情绪特征，ConvLSTM实时检测评估愤怒情绪值的占比。通过在视频和音频两个维度进行分析，准确分析校园场景中学生的视频行为和音频情绪，对可能发生的暴力行为进行及时监测与预警，使学校和相关部门能够更及时地介入和解决问题，有效避免校园暴力的发生与传播。

**项目目标**
要求识别成功率达到90%以上。
